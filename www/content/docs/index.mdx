A modern, universal database management studio for any database. Think of it as a pgAdmin alternative that's easier to use.

db-studio gives you a clean, spreadsheet-like interface to browse and manage your database tables, run SQL queries, and more.

## What Can You Do?

- **Browse tables** like a spreadsheet with easy editing
- **Live mode** refreshes the grid every second and highlights changed rows and cells
- **Run SQL queries** with a built-in editor that has autocomplete
- **Manage your data** - add, edit, delete rows and columns
- **Manage indexes** - see, create, and drop [indexes](/docs/indexes)
- **Export data** to CSV, JSON, or Excel files
- **Import data** from CSV, JSON, or Excel files
- **Command palette** to jump to tables and run actions from the keyboard
- **AI assistant** to ask questions about your data in plain English, with your own key for Gemini, OpenAI, Anthropic, Grok, or OpenRouter
- **Switch databases** easily when you have multiple databases on the same server

<Callout title="Your Data Stays Yours">
  db-studio runs on your computer and connects to your database directly. Your connection details are never sent anywhere. It sends anonymous usage data, which you can turn off; see the [FAQ](/docs/faq#telemetry). All code is open source so you can check for yourself.
</Callout>
